# Reprog30 — site web

Site vitrine statique prêt pour GitHub + Vercel.

## Déploiement Vercel
1. Créer un dépôt GitHub et y envoyer `index.html` et `style.css`.
2. Dans Vercel, choisir **Add New Project** puis importer le dépôt.
3. Framework Preset : **Other** (ou aucun framework).
4. Build Command : laisser vide.
5. Output Directory : laisser vide.
6. Deploy.

Le site fonctionne sans serveur ni base de données.
